# Product showcase concepts

All three concepts read the root `apps-data.js`, preserve its categories, and use real screenshots of the listed apps.
The selected Screening room design also powers the homepage.

## Gallery

Cloud #F3F6FA, white #FFFFFF, navy #172B43, blue #245AB5, muted #5E6D80.
Segoe UI carries the interface, with Georgia for the large product statement.
Left-aligned product introduction and featured screenshot lead into a three-column visual catalogue.
The characteristic detail is a generous floating screenshot composition beside a quiet, confident headline.

```text
brand                         concept switcher
product statement             featured screenshot
frequently used shortcuts
category filters                         search
product screenshot | product screenshot | product screenshot
```

## Workspace

Mist #EDF2F2, white #FFFFFF, deep teal #143F43, green #23665C, slate #526A70.
Segoe UI throughout, with compact controls and restrained heading scale.
A persistent category sidebar frames a dense list with screenshots and an app-detail drawer.
The characteristic detail is quick access: each product reads as a launchable tool, with learning notes one click away.

```text
sidebar | title                         search
        | frequently used shortcuts
        | screenshot | description | launch
        | screenshot | description | launch
```

## Screening room

The selected concept offers Mineral (#EEF3EF, #34664E), Coral (#FCECE7, #BD4B38, #F3A080) and Mulberry (#29232B, #E1B8CB).
Georgia headings with Segoe UI interface copy.
A category sidebar sits beside a large selected-product stage and a category-organized catalogue.
Previous and next arrows, keyboard navigation and a project selector change the stage without auto-playing or taking over scrolling.

```text
brand                  appearance choices
sidebar | frequently used shortcuts
sidebar | selected product copy | large screenshot with arrows
sidebar | project selector buttons
sidebar | catalogue and search
```

## Review against the brief

These are three different browsing structures, not merely recoloured cards.
App names, working links and categories come from the existing directory.
The compact workspace prioritizes returning visitors; the gallery balances discovery with access; the screening room prioritizes project exploration.
No biography, particles, custom cursor, scroll hijacking or automatic carousel is needed for this product-focused brief.
Pins remain independent of filters and appear above the catalogue; browser storage retains them across visits on the same browser and origin.
Draft learning notes must be reviewed by the owner before publication.
Unverified technology information is explicitly labelled.
